# الديمو على GitHub Codespaces

هذا المجلد يجعل المشروع يعمل بضغطة واحدة داخل Codespaces.

## كيف يعمل؟

عند إنشاء Codespace من هذا الريبو، تقوم GitHub تلقائياً بتشغيل ملف
`docker-compose.yml` كاملاً: قاعدة بيانات Postgres، ثم الخادم (الذي ينتظر
قاعدة البيانات ويجهّز الجداول والبيانات التجريبية)، ثم الواجهة الأمامية.
لا حاجة لتشغيل أي أمر يدوياً — فقط انتظر حتى تكتمل عملية البناء والتشغيل،
ثم افتح المنفذ **5173** من تبويب Ports في Codespaces.

> ملاحظة: لا يوجد هنا `postStartCommand` يشغّل `docker compose up`، لأن
> تشغيل Compose هو وظيفة بيئة devcontainer نفسها وليس أمراً يُنفَّذ داخل
> الحاوية (لا يوجد Docker CLI داخل حاوية الويب). إعداد
> `dockerComposeFile` في `devcontainer.json` هو ما يبدأ الخدمات الثلاث.
> وإعداد `overrideCommand: false` يحافظ على أمر خدمة `web` من compose
> (خادم Vite) بدل استبداله بأمر إبقاء افتراضي.

## الدخول للديمو

- افتح المنفذ 5173 (الواجهة) من تبويب Ports.
- كود الشركة: `COMP001` — اسم المستخدم: `admin` — كلمة المرور: `admin123`
- هذه قيم ديمو معلنة فقط — غيّرها فوراً في أي استخدام حقيقي (راجع قسم
  "جرّب الديمو" في README.md).

## التشغيل المحلي (بدون Codespaces)

نفس الأمر الواحد من جذر المشروع:

```bash
docker compose up --build
```

ثم افتح http://localhost:5173

لإيقاف كل شيء وحذف الحاويات: `docker compose down` (تبقى البيانات في
الـ volume؛ لحذفها أيضاً أضف `-v`).
