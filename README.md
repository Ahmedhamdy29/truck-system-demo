# نظام إدارة الشاحنات - Truck Management System

## نظرة عامة على النظام

نظام إدارة الشاحنات هو تطبيق ويب متكامل مصمم لإدارة أسطول الشاحنات بكفاءة عالية. يوفر النظام واجهة سهلة الاستخدام للمديرين والسائقين لتتبع وإدارة جميع العمليات المتعلقة بالشاحنات.

### المميزات الرئيسية
- **نظام متعدد الشركات**: كل شركة لها بياناتها المنفصلة والمؤمنة
- **إدارة الشاحنات**: تسجيل وإدارة معلومات الشاحنات
- **إدارة الرحلات**: تتبع الرحلات وحالتها
- **إدارة المصاريف**: تسجيل وتتبع جميع المصاريف
- **إدارة الصيانة**: جدولة وتتبع عمليات الصيانة
- **التقارير**: تقارير شاملة ومفصلة
- **نظام المستخدمين**: إدارة صلاحيات المديرين والسائقين
- **الأمان المتقدم**: حماية كاملة لبيانات كل شركة

## المتطلبات التقنية

### المتطلبات الأساسية
- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn
- متصفح ويب حديث

### التقنيات المستخدمة
- **الواجهة الأمامية**: React + TypeScript + Vite
- **الواجهة الخلفية**: Node.js + Express
- **قاعدة البيانات**: SQLite (قابلة للترقية إلى PostgreSQL)
- **التصميم**: Tailwind CSS
- **الرسوم البيانية**: Recharts
- **المصادقة**: JWT مع تشفير bcrypt

## ⚡️ الآن النظام يعمل مع PostgreSQL

### إعداد قاعدة البيانات (PostgreSQL)

1. تأكد من تثبيت PostgreSQL على جهازك.
2. أنشئ قاعدة بيانات باسم `truck_system` (تم شرح ذلك في الخطوات السابقة).
3. تأكد من وجود مستخدم باسم `postgres` وكلمة مرور `Asd123ah` (يمكنك تغييرها في `server/database/database.js` إذا لزم الأمر).
4. لا حاجة لأي إعدادات إضافية، سكريبت التهيئة يقوم بإنشاء الجداول تلقائيًا.

### إعداد وتشغيل الخادم (Backend)

```bash
npm install
node server/scripts/initDatabase.js   # لتجهيز الجداول لأول مرة
node server/server.js                 # لتشغيل الخادم
```

### إعداد وتشغيل الواجهة الأمامية (Frontend)

```bash
npm run dev
```

### ملاحظات هامة:
- جميع البيانات الآن تُخزن في PostgreSQL وليس SQLite.
- يمكنك تعديل إعدادات الاتصال بقاعدة البيانات من ملف `server/database/database.js`.
- إذا غيرت كلمة مرور أو اسم قاعدة البيانات، حدثها في نفس الملف.

## دليل الاستخدام

### تسجيل شركة جديدة
1. انتقل إلى صفحة "تسجيل شركة جديدة"
2. املأ بيانات الشركة:
   - **اسم الشركة**: اسم الشركة
   - **كود الشركة**: كود فريد للشركة (مثال: COMP001)
   - **البريد الإلكتروني**: بريد الشركة
   - **رقم الهاتف**: هاتف الشركة
   - **العنوان**: عنوان الشركة
3. املأ بيانات المدير:
   - **اسم المدير**: اسم مدير الشركة
   - **اسم المستخدم**: اسم المستخدم للمدير
   - **كلمة المرور**: كلمة المرور
   - **البريد الإلكتروني**: بريد المدير
4. اضغط "إنشاء الشركة"

### تسجيل الدخول
1. افتح التطبيق في المتصفح
2. أدخل:
   - **كود الشركة**: كود الشركة المسجلة
   - **اسم المستخدم**: اسم المستخدم
   - **كلمة المرور**: كلمة المرور
3. اضغط "تسجيل الدخول"

### البيانات التجريبية
- **كود الشركة**: `COMP001`
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `admin123`

### لوحة التحكم (Dashboard)
لوحة التحكم تعرض نظرة عامة على النظام:
- **إجمالي الشاحنات**: عدد جميع الشاحنات في الشركة
- **الرحلات النشطة**: عدد الشاحنات في رحلات حالياً
- **إجمالي المصاريف**: مجموع جميع المصاريف بالريال السعودي
- **الشاحنات في الصيانة**: عدد الشاحنات تحت الصيانة
- **الرحلات النشطة**: قائمة بالرحلات الجارية مع نسبة الإنجاز

### إدارة الشاحنات

#### عرض الشاحنات
- انتقل إلى صفحة "الشاحنات"
- ستجد قائمة بجميع شاحنات شركتك مع معلوماتها الأساسية
- يمكنك تصفية الشاحنات حسب الحالة (متاحة، في رحلة، صيانة)

#### إضافة شاحنة جديدة
1. اضغط على زر "إضافة شاحنة"
2. املأ المعلومات المطلوبة:
   - **رقم الشاحنة**: رقم تعريفي للشاحنة
   - **الموديل**: موديل الشاحنة
   - **سنة الصنع**: سنة تصنيع الشاحنة
   - **رقم اللوحة**: رقم لوحة الشاحنة
   - **رقم المحرك**: رقم محرك الشاحنة
   - **رقم الشاسيه**: رقم شاسيه الشاحنة
   - **حمولة الشاحنة**: الوزن الأقصى المحمل
   - **اسم السائق**: اسم سائق الشاحنة
3. اضغط "حفظ"

#### تعديل شاحنة
1. اضغط على الشاحنة المطلوبة
2. ستنتقل إلى صفحة تفاصيل الشاحنة
3. اضغط على زر "تعديل"
4. عدل المعلومات المطلوبة
5. اضغط "حفظ"

#### حذف شاحنة
1. في صفحة تفاصيل الشاحنة
2. اضغط على زر "حذف"
3. أكد الحذف

### إدارة الرحلات

#### عرض الرحلات
- انتقل إلى صفحة "الرحلات"
- ستجد قائمة بجميع رحلات شركتك مع حالتها
- يمكنك تصفية الرحلات حسب:
  - **الشاحنة**: رحلات شاحنة محددة
  - **الحالة**: نشطة، مكتملة، متأخرة
  - **الفترة الزمنية**: هذا الشهر، الشهر الماضي، آخر 3 أشهر، هذا العام، العام الماضي

#### إضافة رحلة جديدة
1. اضغط على زر "إضافة رحلة"
2. املأ المعلومات المطلوبة:
   - **الشاحنة**: اختر الشاحنة
   - **الوجهة**: وجهة الرحلة
   - **الاتجاه**: ذهاب أو عودة
   - **تاريخ البداية**: تاريخ بداية الرحلة
   - **تاريخ الانتهاء المتوقع**: تاريخ انتهاء الرحلة المتوقع
   - **الإيرادات المتوقعة**: الإيرادات المتوقعة من الرحلة
3. اضغط "حفظ"

#### إنهاء رحلة
1. في قائمة الرحلات، ابحث عن الرحلة المطلوبة
2. اضغط على زر "إنهاء الرحلة"
3. أدخل تاريخ الانتهاء الفعلي
4. اضغط "تأكيد"

#### حذف رحلة
1. في قائمة الرحلات
2. اضغط على زر "حذف" بجانب الرحلة
3. أكد الحذف

### إدارة المصاريف

#### عرض المصاريف
- انتقل إلى صفحة "المصاريف"
- ستجد قائمة بجميع مصاريف شركتك
- يمكنك تصفية المصاريف حسب:
  - **الشاحنة**: مصاريف شاحنة محددة
  - **النوع**: وقود، صيانة، رسوم، أخرى
  - **الفترة الزمنية**: هذا الشهر، الشهر الماضي، آخر 3 أشهر، هذا العام، العام الماضي

#### إضافة مصروف جديد
1. اضغط على زر "إضافة مصروف"
2. املأ المعلومات المطلوبة:
   - **الشاحنة**: الشاحنة المرتبطة بالمصروف
   - **النوع**: نوع المصروف (وقود، صيانة، رسوم، أخرى)
   - **المبلغ**: قيمة المصروف
   - **التاريخ**: تاريخ المصروف
   - **الوصف**: وصف تفصيلي للمصروف
   - **الفئة**: فئة المصروف
   - **صورة الإيصال**: رفع صورة الإيصال (اختياري)
3. اضغط "حفظ"

#### تعديل مصروف
1. في قائمة المصاريف
2. اضغط على زر "تعديل" بجانب المصروف
3. عدل المعلومات المطلوبة
4. اضغط "حفظ"

#### حذف مصروف
1. في قائمة المصاريف
2. اضغط على زر "حذف" بجانب المصروف
3. أكد الحذف

### إدارة الصيانة

#### عرض سجلات الصيانة
- انتقل إلى صفحة "الصيانة"
- ستجد قائمة بجميع سجلات صيانة شركتك
- يمكنك تصفية السجلات حسب:
  - **الشاحنة**: صيانة شاحنة محددة
  - **النوع**: صيانة دورية، فحص إطارات، تغيير زيت، فحص شامل
  - **الفترة الزمنية**: هذا الشهر، الشهر الماضي، آخر 3 أشهر، هذا العام، العام الماضي

#### إضافة سجل صيانة جديد
1. اضغط على زر "إضافة صيانة"
2. املأ المعلومات المطلوبة:
   - **الشاحنة**: الشاحنة المراد صيانتها
   - **نوع الصيانة**: نوع الصيانة المطلوبة
   - **التاريخ**: تاريخ الصيانة
   - **التكلفة**: تكلفة الصيانة
   - **الوصف**: وصف تفصيلي للصيانة
   - **تاريخ الصيانة القادمة**: تاريخ الصيانة القادمة (اختياري)
3. اضغط "حفظ"

#### حذف سجل صيانة
1. في قائمة سجلات الصيانة
2. اضغط على زر "حذف" بجانب السجل
3. أكد الحذف

- يعرض التقرير:
  - إجمالي المصاريف
  - إجمالي تكلفة الصيانة
  - عدد الرحلات
  - نسبة إنجاز الرحلات

#### تقرير الربحية
- اختر "تقرير الربحية"
- يعرض التقرير لكل شاحنة:
  - إجمالي الإيرادات
  - إجمالي المصاريف
  - إجمالي الصيانة

  - عدد الرحلات
  - حالة الشاحنة

#### تقرير استهلاك الوقود
- اختر "تقرير الوقود"
- يعرض التقرير لكل شاحنة:
  - عدد عمليات التزود بالوقود
  - إجمالي مبلغ الوقود
  - متوسط التكلفة للعملية

#### تقرير كفاءة السائقين
- اختر "تقرير السائقين"
- يعرض التقرير لكل سائق:
  - إجمالي الرحلات
  - الرحلات المكتملة
  - نسبة الكفاءة

### تصدير التقارير
- في أي صفحة تقارير
- اضغط على زر "تصدير Excel"
- سيتم تحميل التقرير بصيغة Excel

## الإعدادات والتكوين

### متغيرات البيئة
أنشئ ملف `.env` في مجلد الخادم:
```env
PORT=3001
JWT_SECRET=your-super-secret-jwt-key
DB_PATH=./database/trucks.db
UPLOAD_PATH=./uploads
NODE_ENV=development
```

### تكوين قاعدة البيانات
النظام يستخدم SQLite كقاعدة بيانات. الجداول الرئيسية:
- **companies**: الشركات
- **users**: المستخدمين (مرتبط بالشركة)
- **trucks**: الشاحنات (مرتبط بالشركة)
- **trips**: الرحلات (مرتبط بالشركة)
- **expenses**: المصاريف (مرتبط بالشركة)
- **maintenance_records**: سجلات الصيانة (مرتبط بالشركة)

## الأمان

### نظام متعدد الشركات
- كل شركة لها بياناتها المنفصلة تماماً
- لا يمكن لشركة الوصول لبيانات شركة أخرى
- جميع الطلبات تتحقق من انتماء المستخدم للشركة الصحيحة

### المصادقة
- يستخدم النظام JWT للمصادقة
- جميع الطلبات (عدا تسجيل الدخول) تتطلب توكن صالح
- التوكن يحتوي على معلومات الشركة
- التوكن صالح لمدة 24 ساعة

### الصلاحيات
- المدير: صلاحيات كاملة على شركته فقط
- السائق: صلاحيات محدودة على شاحنته فقط

### حماية البيانات
- تشفير كلمات المرور باستخدام bcrypt
- Rate limiting للحماية من الهجمات
- CORS محدود للدومينات المسموحة
- التحقق من انتماء البيانات للشركة في كل طلب

## استكشاف الأخطاء

### مشاكل شائعة

#### مشكلة CORS
إذا واجهت مشكلة CORS:
1. تأكد من أن الخادم يعمل على المنفذ 3001
2. تأكد من إعدادات CORS في `server/server.js`
3. أعد تشغيل الخادم

#### مشكلة قاعدة البيانات
إذا واجهت مشكلة في قاعدة البيانات:
1. تأكد من وجود مجلد `server/database`
2. شغل `npm run init-db` لإعادة إنشاء الجداول
3. تأكد من صلاحيات الكتابة على المجلد

#### مشكلة في الواجهة
إذا واجهت مشكلة في الواجهة:
1. تأكد من تثبيت جميع المتطلبات: `npm install`
2. امسح cache المتصفح
3. أعد تشغيل خادم التطوير

### سجلات الأخطاء
- سجلات الخادم تظهر في الطرفية
- أخطاء الواجهة تظهر في console المتصفح
